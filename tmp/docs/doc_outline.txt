P0130	[]	第一章为绪论，主要介绍研究背景与研究意义，分析当前柔性作业车间调度与设备维护协同优化领域的发展现状，并明确本文的研究内容与技术路线。
P0131	[]	第二章为基础理论与背景知识，系统梳理本文所涉及的关键理论基础。首先介绍马尔可夫决策过程及强化学习的基本概念，包括价值函数、策略表示以及探索与利用机制；随后分别阐述基于价值的方法与基于策略梯度的方法，并重点介绍DQN、Double DQN以及PPO等典型算法；进一步引入不完全信息决策框架，说明POMDP及POMCP的基本思想；最后，对时间序列建模方法进行综述，为后续RUL预测模型的设计提供理论支撑。
P0132	[]	第三章为问题描述与建模，从系统层面对生产调度与设备退化过程进行统一建模。该章首先描述研究问题及其约束条件，然后建立机器性能退化与剩余使用寿命（RUL）的建模方法，并结合数据集特征分析退化规律；在此基础上，构建柔性作业车间的调度模型，包括作业到达、工序加工、机器分配以及健康感知约束等内容，从而为后续算法设计提供形式化问题基础。
P0133	[]	第四章为算法设计，围绕“预测—维护—调度”三个层次展开。首先设计基于GRU的RUL预测模型，实现设备健康状态的动态估计；随后构建维护智能体，分别从分层DDQN、单层DDQN以及POMCP三种角度进行建模与分析；最后设计调度智能体，包括基于层级强化学习的THDQN方法与基于策略梯度的PPO方法，并说明其状态表示、决策结构及优化目标。
P0134	[]	第五章为实验设计、结果与分析。该章首先说明实验目标与整体分析思路，并给出数据、环境及算法参数设置；随后对六组调度—维护组合进行逐一分析，并结合甘特图、RUL演化曲线及动作分布等结果进行说明；在此基础上，从横向与纵向两个维度对不同方法进行对比分析，进一步探讨不同策略结构之间的协同关系，并对最优组合的形成机制进行解释。

P0515	[]	第1条规则为“最早交期优先+最早空闲机器分配（EDD + Earliest Idle Machine）”。该规则首先在当前可调度工序中选择所属作业交期 dj 最早的工序，再将该工序分配给其候选机器集合中当前最早可用的机器。该规则强调交期约束，适用于需要优先控制作业拖期风险的场景。
P0516	[]	第2条规则为“最早交期优先+最短加工时间机器分配（EDD + Shortest Processing Time Machine）”。与第1条规则相同，该规则同样先依据最早交期原则确定优先工序，但在机器分配阶段不再采用最早空闲原则，而是从候选机器中选择使当前工序加工时间 pjkm 最短的机器。该规则在兼顾交期压力的同时，进一步追求单工序加工效率。
P0517	[]	第3条规则为“最大加权拖期风险优先+最短加工时间机器分配”。该规则首先计算每个候选工序所属作业的加权拖期风险，即根据作业权重 wj 与预估拖期程度共同衡量其紧迫性，并优先选择风险最大的工序。随后，在可行机器中选择加工时间最短的设备执行。该规则特别适用于存在不同作业重要度差异、且需要突出高权重紧急订单的场景。
P0518	[]	第4条规则为“最短剩余加工时间优先+最短加工时间机器分配（SRPT + SPT Machine）”。该规则先对作业的剩余加工需求进行估计，优先选择剩余加工时间最短的作业对应工序，再为其分配加工时间最短的机器。该规则强调尽快完成短作业，有助于提升系统吞吐效率并减少在制品积压。
P0519	[]	第5条规则为“最长剩余加工时间优先 + 最早空闲机器分配（LRPT + Earliest Idle Machine）”。与第4条规则相对，该规则优先选择剩余加工时间最长的作业对应工序，并分配给当前最早空闲的候选机器。该规则的核心思想在于优先处理长作业，以避免大加工量任务长期滞留系统，从而影响整体完工节奏。
P0520	[]	第6条规则为“最小松弛时间优先+最早空闲机器分配（Minimum Slack + Earliest Idle Machine）”。该规则依据作业当前松弛量SLj(t)=dj-Cj(t)进行排序，优先选择松弛时间最小的工序，即最接近交期边界的任务，然后将其分配给最早可用的机器。该规则能够直接反映作业的交付紧迫性，对降低即将逾期作业的风险具有较强针对性。
